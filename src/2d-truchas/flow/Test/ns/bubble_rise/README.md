# Rising-bubble test

This exploratory four-process regression starts a light-fluid disk at rest in
the lower part of a heavy-fluid column.  Downward body acceleration causes the
bubble to rise and deform.  There is no analytic solution; the light-fluid
volume fraction is compared with the stored four-process reference using a
relative L1 norm.  Velocity and pressure are checked only for finite,
nontrivial flow behavior.
