# Solidification with flow

This four-process regression couples buoyancy-driven flow to solidification
of a phase-change material.  A horizontal temperature difference produces
flow under downward body acceleration while the cold wall produces solid and
mixed cells, eventually producing pure solid cells.  The test checks finite
active-cell flow and thermal states, phase-fraction partitioning, and that
both solidification and flow occur.

The problem is a version of the Voller--Prakash (1987) benchmark problem.
